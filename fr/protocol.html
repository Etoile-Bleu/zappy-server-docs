Zappy Serveur

Vue d'ensemble de la couche protocole

La couche protocole traduit entre les octets TCP bruts et les valeurs Rust typées. Elle comporte deux moitiés délibérément symétriques et indépendantes :

graph LR
    subgraph "Entrant (parsage)"
        AI_RAW["'Forward\n'"] --> AIP["protocol::ai::parse()"]
        AIP --> AIT["AiCommand::Forward"]
        GUI_RAW["'bct 3 7\n'"] --> GUIP["protocol::gui::parse()"]
        GUIP --> GUIT["GuiCommand::Bct { x: 3, y: 7 }"]
    end

    subgraph "Sortant (sérialisation)"
        NOT["GuiNotification::PlayerPosition { ... }"] --> FMT["protocol::gui::format()"]
        FMT --> STR["'ppo #1 3 7 2\n'"]
    end

Les trois fonctions sont des fonctions pures : pour une entrée donnée, elles retournent une sortie, ne mutent rien et ne causent aucun effet de bord. Elles sont donc trivialement testables et impossibles à mal utiliser.

Principes de conception partagés

Parse, Don't Validate

Formulé par Alexis King en 2019, ce principe stipule : plutôt que de passer une entrée brute avec une hypothèse de confiance, la parser une fois en un type qui rend les états invalides non représentables.

Appliqué dans toute cette couche : ni app.rs ni aucun handler d'action ne voit jamais un &str brut. Toute valeur qui franchit la frontière de parsage est soit une AiCommand / GuiCommand typée, soit une erreur typée. L'appelant ne peut pas traiter accidentellement une coordonnée Y de tuile comme un id de joueur.

Référence : Parse, don't validate - Alexis King (2019)

Patron Newtype

PlayerId(u32) et EggId(u32) sont des newtypes : des structs à un seul champ qui donnent à un u32 une identité de type distincte. Le compilateur rejette le passage de l'un là où l'autre est attendu, sans coût à l'exécution.

Références :

  • New Type Idiom - Rust By Example
  • Newtype - Rust Design Patterns
  • Item 6: Embrace the newtype pattern - Effective Rust

Pattern matching exhaustif

Le match de Rust sur un enum doit couvrir chaque variante. Ajouter une nouvelle variante GuiNotification sans mettre à jour format() est une erreur de compilation, pas une surprise à l'exécution. Cette complétude imposée par le compilateur élimine toute une catégorie de bugs de protocole.

Référence : Pattern and exhaustiveness checking - Rust Compiler Development Guide
