Zappy Serveur

Introduction

Zappy est un jeu de programmation en réseau où des agents IA autonomes s'affrontent sur une planète 2D toroïdale riche en ressources appelée Trantor. Le serveur est l'arbitre : il gère la simulation, applique le protocole réseau et produit tous les événements observables de la partie.

Ce livre documente uniquement le serveur. Le client IA, l'interface graphique et le pipeline de compilation sont couverts séparément.

Ce que fait le serveur

flowchart TD
    AI["Clients IA<br/>(drones trantorisés)"] -->|"TCP / protocole IA"| S["Serveur"]
    GUI["Clients GUI<br/>(observateurs)"] -->|"TCP / protocole GUI"| S
    S -->|"ppo, pnw, bct …"| GUI
    S -->|"ok / ko / dead"| AI
    S -->|"seg team"| AI
    S -->|"seg team"| GUI

Le serveur remplit cinq responsabilités :

  1. Accepter et classifier les connexions. Chaque nouveau client TCP est Unknown. Sa première ligne l'identifie : GRAPHIC le promut en observateur GUI ; un nom d'équipe valide le promut en joueur IA et fait éclore un drone trantorisé depuis un œuf de l'équipe.

  2. Piloter l'horloge de simulation. L'argument de fréquence -f détermine combien d'unités de temps s'écoulent par seconde. Chaque unité de temps déclenche les minuteries de nourriture, les minuteries d'action et la régénération périodique des ressources.

  3. Exécuter les actions de jeu. Lorsque la minuterie d'action d'un client IA expire, le serveur exécute l'action : déplacer un joueur, transférer une ressource, lancer une incantation, etc.

  4. Diffuser les notifications GUI. Après chaque changement d'état, le serveur sérialise une GuiNotification typée et l'envoie à tous les clients GUI connectés.

  5. Appliquer la condition de victoire. Lorsque six joueurs de la même équipe atteignent le niveau 8, le serveur diffuse seg nom_equipe à tous les clients.

Démarrage rapide

# Compiler le serveur (Linux ou WSL)
cd server
cargo build --release

# Lancer avec deux équipes, 6 clients chacune, 100 ticks/s
./target/release/server -p 4242 -x 20 -y 20 -n red blue -c 6 -f 100
